# Bank-Management-system
Bank Management System is a console-based application developed in C++ that helps manage basic banking operations. The system allows users to create new accounts, deposit money, withdraw money, check account balances, and view customer information. It stores important details such as account number, customer name, password, and account balance.

The project uses concepts of Object-Oriented Programming (OOP) such as classes, objects, encapsulation, and functions. File handling can also be used to save customer records permanently. This system reduces manual work, improves record management, and provides a simple way to perform banking transactions efficiently.

Main Features:
• Create Account
• Login and Logout
• Deposit Money
• Withdraw Money
• Check Balance
• Display Account Information
• Transaction History
• Save and Load Data Using Files
